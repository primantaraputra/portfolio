Aplikasi Web Laundry Yenny Telang & Pengujian Sistem

Sistem Manajemen Kasir & Rekapitulasi Laporan Keuangan Teruji Quality Assurance • 2026

07 / 10
Pengujian: White Box (Basis Path) & Black Box Testing
Status: Web App & Dataset Simulasi Uji Stres QA

LATAR BELAKANG & KEBUTUHAN OPERASIONAL UMKM

Laundry Yenny di kawasan Telang, Madura membutuhkan sistem pencatatan digital untuk memantau omzet bulanan, mengontrol transaksi masuk harian, rekapitulasi item pakaian yang telah diambil pelanggan, serta meminimalisir kesalahan perhitungan kas manual.

FITUR UTAMA & METODOLOGI PENGUJIAN PERANGKAT LUNAK

Dashboard Laporan (Data Simulasi Uji QA): Tangkapan layar menggunakan dataset dummy pengujian untuk memverifikasi penanganan kondisi batas (edge cases)—seperti validasi 116 pembatalan transaksi, konsistensi status item diambil, dan kalkulasi reset omzet periodik.
Pengujian White Box Testing: Analisis struktur kode internal, perancangan diagram alir kendali (flow graph), serta verifikasi basis path testing dan cyclomatic complexity guna memastikan seluruh percabangan logika dieksekusi tanpa celah.
Pengujian Black Box Testing: Pengujian fungsionalitas antarmuka menggunakan teknik Equivalence Partitioning dan Boundary Value Analysis untuk validasi formulir input bobot kiloan pakaian, tarif layanan, dan keakuratan total tagihan kasir.
